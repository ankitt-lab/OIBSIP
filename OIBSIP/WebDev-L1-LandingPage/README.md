# NovaFit Landing Page

## Project Overview

NovaFit is a modern and responsive fitness and wellness landing page created as part of the Oasis Infobyte Web Development Internship.

## Technologies Used

- HTML5
- CSS3

## Features

- Sticky navigation bar
- Hero section with headline and call-to-action buttons
- Features section
- About section
- Testimonials section
- Contact section
- Responsive design for desktop, tablet, and mobile
- CSS Grid and Flexbox
- Consistent color palette
- Mobile-friendly layout
